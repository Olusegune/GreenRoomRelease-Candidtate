# Greenroom Local 0.5.0 (release candidate)

- `Greenroom Local_0.5.0_x64-setup.exe`: Windows installer (per-user).
- `Greenroom Local_0.5.0_x64_en-US.msi`: MSI installer.
- `Greenroom Local 0.5.0 portable.zip`: standalone app, no install. Needs Microsoft Edge WebView2 (built into Windows 11).

Not code-signed, so Windows SmartScreen may warn. Not update-signed: built without the update key, so there is no in-app update from these files.
Check downloads against `SHA256SUMS.txt`.
